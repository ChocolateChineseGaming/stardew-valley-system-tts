# 0.1.0 游戏内验收

1. 只安装 `StardewMandarin.SystemVoice`，确认原 Qwen 版 Mod 未同时启用。
2. 使用简体中文进入存档，打开 NPC 对白后保持静音；按 F8 后才生成并播放。
3. 再按 F8 应停止旧声音并从当前内容开头重读。
4. 翻页、切换任务、关闭菜单或返回标题时应立即停止旧语音。
5. 任务详情按标题、说明、目标顺序朗读；信件只朗读正文；电视节目按当前页朗读。
6. 按 F10 左右切换已安装的普通话声音，并调整系统语速、播放速度和音量；关闭设置页后重新朗读并确认生效。
7. 在 F10 中分别关闭任务、信件和电视朗读，确认其他内容不受影响。
8. 把 `FallbackVoice` 改为 `say -v '?'` 中存在的中文声音，执行 `system_voice_reload` 后确认生效。
9. 使用不存在的声音名时应记录错误但不影响游戏继续运行；修复配置后执行 `system_voice_reload` 恢复。
10. 退出游戏并检查 Mod 目录：动态语音应保存在 `cache`，缺失文本应记录在 `missing-dialogue.jsonl`。
